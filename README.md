# 📦 C++ Inventory Management System

A robust, console-based inventory management application built entirely with C++ as a collaborative team project.

## Project Overview
* **Role:** Project Manager (Led project planning, task delegation, and execution)
* **Language:** C++
* **Concepts Used:** Object-Oriented Programming (OOP) and File I/O Streams

## Core Features
* **Stock Tracking:** Efficiently monitor and manage available inventory.
* **Item Management:** Add new items, update existing stock details, and remove outdated entries.
* **Search Functionality:** Quickly locate specific items within the database.
* **Data Persistence:** Utilizes C++ File Handling to securely save and retrieve inventory data locally.

## Leadership & Management
As the Project Manager, I oversaw the entire development lifecycle. I was responsible for coordinating the team, organizing the code structure, and ensuring that all project milestones and deadlines were successfully met.
